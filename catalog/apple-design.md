# apple-design

**Purpose:** Apply Apple-inspired physical interaction principles to web UI.

**Invocation:** automatic

**Use when:** The task specifically concerns direct manipulation, velocity handoff, interruptible springs, gestures or Apple-style materials and interaction behavior.

**Do not use when:** Making every project look like Apple, generic UI redesign, or treating this as a native Swift programming guide.

**Overlaps and default:** Supporting guidance for physical interaction behavior. Impeccable owns general UI direction; animate owns a concrete web animation build, and write-swift owns Swift implementation.

**Requirements:** Target interaction and project design constraints. Browser/pointer testing is needed for implemented gestures; real-device checks are needed for mobile feel.

**Expected output:** Interaction decisions or implementation guidance for responsive, continuous and interruptible behavior.

**Positive example:** "Make this draggable web sheet inherit release velocity and remain interruptible."

**Negative example:** "Resolve this Swift actor-isolation compiler error."
