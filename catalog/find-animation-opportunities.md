# find-animation-opportunities

**Purpose:** Identify currently unanimated interactions that would benefit from purposeful motion.

**Invocation:** automatic

**Route:** Find where motion would help

**Synonyms:** where to add motion; animation opportunities; interaction feedback; motion audit

**Use when:** The user wants a short list of animation opportunities and reasons before implementation.

**Do not use when:** Fixing existing animations, implementing changes immediately, or adding decoration everywhere.

**Overlaps and default:** This proposes new opportunities; improve-animations audits existing motion. Hand accepted construction work to animate in a separate implementation phase.

**Requirements:** Read access to the UI/code and usage context. Source code remains unchanged; visual evidence helps evaluate actual behavior.

**Expected output:** A small prioritized set of proposals with concrete motion values, plus rejected opportunities.

**Positive example:** "Where would motion help this screen? Give recommendations only."

**Negative example:** "Fix the stuttering animation already running in this drawer."
