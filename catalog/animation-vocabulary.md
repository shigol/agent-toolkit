# animation-vocabulary

**Purpose:** Translate a plain-language description of motion into the terminology in its glossary.

**Invocation:** automatic

**Use when:** The user asks what an observed effect is called or needs precise words to describe it.

**Do not use when:** Implementing motion, auditing code, choosing a design system or troubleshooting performance.

**Overlaps and default:** Use this for terminology, then animate only if implementation is requested. Closely related terms should be distinguished rather than treated as interchangeable.

**Requirements:** A description, reference or observable effect. No project runtime is required for a terminology answer.

**Expected output:** The best matching term, its meaning and a small number of relevant alternatives.

**Positive example:** "What is it called when list items appear one after another with a short delay?"

**Negative example:** "Implement staggered entry for this list."
